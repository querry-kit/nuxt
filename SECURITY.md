# Security Policy

## Supported versions

Only the latest published release of `@querry-kit/nuxt` is supported with security updates.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues. Use [GitHub's private vulnerability reporting](https://github.com/querry-kit/nuxt/security/advisories/new) and include a description, reproduction steps, and potential impact.

We will investigate the report and coordinate a fix before public disclosure.
